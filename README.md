# 이름
문자열 덧셈 계산기

# 설명
입력한 문자열에서 숫자를 추출하여 더하는 계산기

## 기능 요구 사항
1. 쉼표(,) 또는 콜론(:)을 구분자로 가지는 문자열을 전달하는 경우 구분자를 기준으로 분리한 각 숫자의 합을 반환한다.
2. 쉼표, 콜론 외의 커스텀 구분자를 지정할 수 있다. 커스텀 구분자는 문자열 앞부분에 "//", "\n" 사이에 정의된다.
3. 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시킨 후 애플리케이션은 종료되어야 한다.

## 입출력
### 입력
구분자와 양수로 구성된 문자열
### 출력
덧셈 결과
```
결과 : 6
```
## 구현할 기능
### InputReader
사용자 입력 처리
### InputParser
입력 문자열을 유효한 데이터로 변환
### Calculator
계산
### OutputWriter
계산 결과 출력
